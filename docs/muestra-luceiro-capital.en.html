Architecture

How it is connected

A single path, from the data source to the company sheet. Each piece does one thing and can be changed without touching the others: connecting Bloomberg will mean adding a provider, not rebuilding the application. Click any piece to see what it does and where it lives in the code.

Everything runs from a single command:.\analisis cargar · importar · ejecutar · fichas · panel · nota · ejecuciones

Design criteria

How it is designed

Eight non-negotiable rules. Each one addresses a specific risk in an analysis tool: deciding on the basis of made-up data, using a figure before it was known, or being unable to explain where a number comes from.

Five ways of saying “there is no number”

When a metric cannot be calculated, the tool says so and explains why. These cases come straight from the latest run on the sample companies.

    Data sources

    Free API connections

    Official, free sources with no sign-up that could cover part of the data before a Bloomberg or FactSet licence is in place. The first four are queried right now from this browser; the others only accept requests from a program and are tested with a Python script included in the project. Nothing shown here is stored in the database.

    Try them here

    Each card sends a real query to the source and shows the exact URL it used, so that it can be repeated anywhere.

    Exchange rates

    European Central Bank · daily reference rates

    Querying

    Fit with the app. It would replace the template’s “Exchange rates” sheet: it uses the same convention (units per 1 euro) and is updated every business day at around 16:00.

    Euro yield curve

    European Central Bank · AAA-rated euro area government debt and €STR

    Querying
    Show the curve data

    Fit with the app. It would provide the risk-free benchmark to calculate each bond’s spread with our own consistent method, instead of relying on the spread delivered by each provider.

    Issuer identification

    GLEIF · global register of LEI codes

    Querying
    Try:

    Fit with the app. It would fill in and check the LEI column of the “Issuers” sheet, flag lapsed LEIs and make it possible to group issuers from the same group through their parent.

    Macroeconomic context

    World Bank · indicators by country

    Querying

    Fit with the app. Context on each company’s country, shown on its company sheet. It would not feed into the scores: it describes the environment, not the company.

    Python only

    These sources do not accept queries from a web page, but they do from a program. They are all tested at once with uv run python scripts\probar_apis.py; the results shown here come from the test run on 20/10/2026.

    SEC EDGAR · US financial statements

    Accounts of every US listed company in XBRL format, each figure with its filing date: a natural fit with point-in-time reading. It would cover the US companies in the universe.

    Result: Apple Inc.: net income for the financial year ended 27/09/2025 = 112,010 M USD, filed on 31/10/2025.

    Free, no key needed. It asks callers to identify themselves with a name and an email address (ANALYSIS_HTTP_USER_AGENT variable) and to make no more than 10 requests per second.

    FRED · market credit spreads

    ICE BofA spread indices (OAS) by credit quality, in euros and in dollars. They would serve as a market gauge alongside each bond’s spread versus its rating bucket.

    Result: euro high-yield spread of 331 bp on 16/10/2026; history available from 20/10/2023.

    Free, no key needed for the CSV download. Because of the ICE licence it only offers the last three years.

    ESMA FIRDS · bond reference data

    European register of financial instruments: name, issuer (LEI), currency, nominal amount, coupon and maturity of every bond traded in the EU. It could fill in and check the “Bonds” sheet.

    Result: XS2289133915, UniCredit S.p.A. EO-Preferred MTN 2021(26): coupon 0.325%, maturity 19/01/2026, 1,000 M EUR, issuer LEI 549300TRUWO2CD2G5692.

    Free, no key needed. Searches by ISIN are fast; broad searches are slow.

    OpenFIGI · from ISIN to ticker

    The open identifier system maintained by Bloomberg. It maps an ISIN to the ticker and exchange of each listing, which is what will be needed to request data from Bloomberg.

    Result: ES0144580Y14 → IBE SM (IBERDROLA SA, FIGI BBG000BC49N1).

    Free. Without a key it allows 25 requests per minute; with a free key, more.

    Bloomberg and FactSet via API: the end goal

    Complete prices, financial statements and ratings will require a paid provider. The application is already prepared for it: it will be one more provider meeting the same contract as the Excel template and the sample data.

    To be settled before connecting it

    • What the fund subscribes to: Terminal, Data License or API.
    • Credentials, stored in .env and never in the code.
    • Sign-off from IT: the Bloomberg library installs executables.
    • That the licence allows the data to be stored locally and used for scoring.

    On this computer

    Try it today

    Everything runs locally with the official Python, with no servers or new installations. From the project folder, in PowerShell:

    .\analisis demo

    Loads the sample data, analyses two dates and generates the company sheets and the ranking in the output folder.

    .\analisis panel

    Opens the dashboard in the browser. It can only be opened from this computer.

    .\analisis plantilla --ejemplo

    Creates the sample Excel workbook in data\import to show how it is filled in with real data.

    .\analisis importar data\import\mis-datos.xlsx

    Validates and loads a workbook with real data. If there are errors, it loads nothing and reports the sheet, row and column.

    uv run python scripts\probar_apis.py

    Checks the nine free APIs from Python and shows one data point from each. It stores nothing.

    .\analisis ejecuciones

    Lists each run with its date, the data it used, the methodology and the code version.
